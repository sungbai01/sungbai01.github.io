# 갈피 — 대화를 간직하는 서재

RisuAI 채팅 로그를 책장에 보관하고, 실제 종이책처럼 페이지를 넘겨 읽는 개인 서재입니다.

## 시작

```sh
npm install
npm run dev
```

React 19.3.1, Tailwind CSS 4.3.3, Vite, TypeScript, StPageFlip으로 작성했습니다.
GitHub Pages의 루트 주소에 배포하도록 설정되어 있습니다. `main`으로 푸시하면 GitHub Actions가 사이트 파일을 생성하고 게시합니다.

## 사용

- 서재 상단 **이어읽기**는 책갈피가 있는 책을 작게 모아 보여 줍니다. 아래 목록 제목은 **책장**입니다.
- 읽는 위치가 책갈피와 다를 때 서재로 돌아가면 책갈피를 넣거나 옮길지 확인합니다. 그냥 나가기도 가능합니다. 자동 읽기 기록은 남기지 않습니다.
- 개별 책과 책장 전체 꾸미기는 같은 항목을 사용합니다. 기본 네 색과 에셋 테두리에서 추출한 사용자 색을 고릅니다. 앞·뒷표지 파일 업로드 대신 기본값으로 되돌리기를 제공합니다. 에셋 관리에도 기본값 복원이 있습니다.
- 뒷표지는 책 제목과 숫자를 표시하지 않는 Code 39 바코드를 사용합니다. 바코드의 숨은 값은 155788848입니다. [인코딩 참고](https://github.com/lindell/JsBarcode/blob/master/src/barcodes/CODE39/index.js). 본문 다음에는 빈 속표지를 거친 뒤 두꺼운 뒷표지가 닫힙니다.

- 가져오기(+)에서 RisuAI JSON, TXT, HTML 파일, HTML embedded(표 형식으로 저장한 HTML/TXT)를 선택합니다. JSONL과 Markdown도 지원합니다. 기본으로 켜진 **인풋 제거**는 사용자·시스템 메시지를 빼고 캐릭터 대화만 저장합니다. 원문 전체를 저장하려면 끄세요. 백업 복원은 이 설정과 관계없이 원문을 보존합니다.
- RisuAI TXT에는 역할 정보가 없으므로 인풋 제거 시 원래 `캐릭터명_날짜_chat.txt` 파일명이 필요합니다. HTML embedded도 역할이 없어 첫 인사의 캐릭터명과 일치하는 대화만 남깁니다. 그룹 대화의 모든 캐릭터를 정확히 보존하려면 역할 정보가 있는 JSON이나 HTML 파일을 사용하세요.
- 가져오기는 [RisuAI 공식 내보내기 코드](https://github.com/kwaroran/Risuai/blob/main/src/ts/characters.ts)의 JSON 메시지 역할, HTML `.idat`, Character/Message 표 구조에 맞춥니다. HTML은 실행하지 않고 텍스트로 읽습니다.
- 책 표지나 책등을 눌러 책을 펼칩니다. 데스크톱은 두 쪽, 모바일은 한 쪽으로 읽습니다.
- 페이지 중간을 잡아 드래그하거나 클릭·스와이프해서 넘깁니다. 좌우 방향키, PageUp/Down, 휠도 같은 넘김 애니메이션을 사용합니다. 하단 방향 버튼은 제거했습니다. 포인터를 페이지 밖에서 놓거나 입력이 중단돼도 진행하던 넘김을 정리합니다.
- **내 서재**에서 책을 호버하거나 키보드로 접근하면 하단 **…** 메뉴가 나타납니다. 여기서 제목·등장인물·소개·표지 색·앞표지와 뒷표지 이미지를 따로 꾸밉니다. **읽던 책**에서는 수정 메뉴 없이 읽던 책만 봅니다. 책장 이름 옆 연필은 책장 이름과 그 안의 책 제목을 함께 바꿉니다.
- 책장 마지막 권의 스토퍼 뒤 **+**에서 직접 입력한 텍스트를 새 권으로 만듭니다. 책장에 등록한 에셋은 본문에서 `{{img::이름}}`으로 넣습니다.
- 책갈피는 **책장당 하나**입니다. 페이지 위로 살짝 나온 책갈피가 있는 책을 누르면 저장한 위치에서 펼칩니다. 책갈피 자체는 별도 이동 버튼이 아닙니다. 위로 끌어 빼거나 상단 책갈피 버튼을 다시 누르면 제거합니다. 독서 설정에서 기본형과 캐릭터 아이콘·대비되는 제목의 캐릭터형을 선택합니다. 책장 제목 옆과 해당 책에도 표시해 서재에서 위치를 알아볼 수 있습니다. 별도 책갈피 목록 버튼은 제거했습니다. 제목·등장인물 검색, 책갈피 위치 저장, 서재 백업·복원도 제공합니다.
- 첫 방문에는 읽기 예시 4권이 놓입니다. 각 책의 메뉴에서 지울 수 있습니다.
- 긴 로그는 실제 읽기 설정에서 100쪽을 초과하면 분권합니다. 챕터 시작 경계를 우선하며, 한 챕터가 계속되면 100쪽 단위로 나눕니다. 글자 수·메시지 수만으로 미리 나누지 않습니다. 본문은 현재 쪽 주변 최대 9쪽만 렌더링합니다.
- 읽기 화면의 연필을 누르면 펼쳐진 페이지에서 본문을 직접 수정합니다. 입력은 페이지 위에 즉시 표시되며, 저장을 누르면 보관합니다. 취소하면 원문을 유지합니다. 페이지 위의 반복 제목과 ‘계속’ 표시는 제거했습니다. Risu의 강조·서술·대화 표기를 읽기용으로 표시하며 이모지는 본문에서 숨깁니다.
- 페이지 가장자리에 마우스를 올리는 것만으로는 넘김이 시작되지 않습니다. 드래그할 때 잡은 높이를 기준으로 페이지가 접힙니다.
- 책장별 에셋 버튼에서 캐릭터 카드 CHARX/PNG/JSON, 에셋 JSON, 개별 이미지 파일을 등록합니다. 등록된 이름에 대응하는 본문 참조를 만나면 이미지가 한 페이지를 온전히 차지합니다. 이미지는 항상 홀수 페이지(왼쪽)에 배치하며 글은 다음 페이지에서 이어집니다. 카드가 외부 파일 경로만 담은 경우에는 해당 이미지 파일도 추가해야 합니다.
- 캐릭터 카드를 넣으면 앞표지의 중앙 컨테이너에 캐릭터 아이콘을 배치하고 위에 제목, 아래에 01·02 형태의 권 번호를 표시합니다. 표지 기본 색은 아이콘 색을 바탕으로 공식 테두리 픽셀에서 자연스럽게 추출하며 사용자 색으로 보관합니다. 책등은 90도 회전한 제목 구역(최대 두 줄, 말줄임)과 권 번호 구역으로 나뉩니다.
- 위 메뉴의 전체화면 버튼은 메뉴를 감추고 페이지를 화면 전체로 넓힙니다. 화면 위쪽 중앙에 마우스를 가져가거나 키보드로 접근하면 해제 버튼이 내려옵니다. 터치 환경에서는 해제 버튼을 바로 표시합니다.
- 각 책장 제목 옆 휴지통으로 해당 시리즈의 모든 권을 삭제합니다. 다른 책장은 유지하며, 확인창에서 해당 책장만 백업하거나 취소할 수 있습니다. 같은 시리즈의 책등은 크기가 같습니다.
- 끝에서는 별도로 디자인한 뒷표지가 닫힙니다. 데스크톱의 빈 절반에는 **다음 권 읽기**, 모바일에는 표지 안에 같은 버튼이 나타나며, 확인창에서 읽기를 눌러야 다음 권으로 이동합니다.
- 기존 긴 책도 처음 다시 열 때 자동 분권합니다. 내용은 보존하며, 기존 쪽 번호는 분권 후 달라져 읽기 위치가 초기화될 수 있습니다.

## 보관 방식

책은 IndexedDB에, 기본 설정은 브라우저 저장소에 보관합니다. 로그를 서버나 GitHub 저장소로 업로드하지 않습니다. 기기·브라우저 간 자동 동기화는 없으며, 이동하려면 **서재 보관함 → 책장 전체 백업 → 다른 기기에서 복원**을 사용합니다. 브라우저 데이터를 지우기 전에 백업하세요. 웹 폰트는 Google Fonts를 이용하며, 연결할 수 없으면 시스템 글꼴을 사용합니다.

## 디자인 레퍼런스

아래 실제 제품을 조사한 후, 구성 요소를 이 서재에 맞게 적용했습니다. 로고·제품 스크린샷·책 표지 이미지는 복제하지 않았습니다.

| 레퍼런스 | 반영한 요소 |
| --- | --- |
| [Apple Books](https://www.apple.com/apple-books/) | 표지를 중심으로 한 서재, 읽던 책 이어 읽기, 독서 화면의 글자 크기·테마 설정 |
| [mymind — book support](https://mymind.com/new-amp-improved-book-support) | 입체적인 책 형태, 표지 색의 조화, 모바일에서도 유지되는 책 중심 구성 |
| [StPageFlip](https://nodlik.github.io/StPageFlip/) | 종이의 곡면과 그림자가 있는 페이지 넘김, 포인터와 터치 조작 |
| [Radix Colors](https://www.radix-ui.com/colors/docs/palette-composition/scales) | Sand 배경·본문, Jade 동작, Bronze 책갈피. 공식 색상 토큰을 직접 사용합니다. |

자동 마지막 읽기 위치 저장은 제거했습니다. 데이터베이스 갱신 때 이전 진행 저장소와 책의 마지막 쪽 필드를 지우며 본문과 수동 책갈피는 보존합니다. 책갈피가 없는 책은 처음부터 펼칩니다. 넘김 엔진은 `src/vendor/page-flip`의 MIT 라이선스 소스를 사용합니다. 페이지 전체를 매 프레임 순회하던 처리와 종료되지 않는 애니메이션 루프를 수정했습니다.

## 이전 검증 기록

아래는 이전 버전의 기록입니다. 이번 변경부터 사용자 요청에 따라 자동 테스트·브라우저 검증·타입 검사를 실행하지 않습니다. 배포용 파일 생성만 수행하며, 동작 확인은 사용자가 진행합니다.

```sh
node --experimental-strip-types --test tests/volumes.test.ts
npx tsc --noEmit
npm run dev -- --host 127.0.0.1 --port 5174
npx playwright test
npm run build
```

자동 검증은 원문·챕터 보존, 100쪽 분권, 권 순서, 저장의 원자성, 모바일·데스크톱 읽기, 9쪽 렌더링 제한, 버튼·페이지 클릭·중간 드래그·방향키·휠·터치 탭/스와이프, 애니메이션 중 스크롤바 방지, 뒷표지와 다음 권 확인, 본문 편집, 책장별 일괄 삭제와 다른 책장 보존, 같은 시리즈 크기, 네 가지 RisuAI 가져오기 형식과 인풋 제거, 검색, 책갈피, 읽던 위치 복원, 모달 중앙 배치를 포함합니다. Playwright는 설치된 Chrome을 사용합니다.

이전 60쪽 분권 정책의 내부 성능 측정(390×844, CPU 4배 제한, 동일 생성 로그 800메시지, 외부 글꼴 제외):

| 지표 | 수정 전 | 수정 후 |
| --- | --- | --- |
| 현재 엔진에 들어간 쪽 | 2,858 | 48 (나머지는 별도 권) |
| 화면 요소 수 | 24,989 | 163 |
| 열기 | 약 18.7초 | 약 1.8초 |
| 연속 4회 넘김 | 0.66–1.24초 | 0.27–0.30초 |
| JS 힙 | 약 42.1MB | 약 8.6MB |

이는 로컬 자동 측정 결과이며 실제 사용자 기기와 글꼴에 따라 달라집니다.

실제 사용 로그에서는 다음도 확인할 수 있습니다.

- 실제 RisuAI 내보내기 파일을 가져와 대화 내용과 순서를 확인합니다.
- 책장 → 읽기 화면 이동과 한 쪽/두 쪽 전환을 확인합니다.
- 모서리 드래그, 스와이프, 버튼, 방향키로 책장을 넘겨 봅니다.
- 긴 메시지와 긴 문단이 빠짐없이 읽히는지 확인합니다.
- 글자 크기·테마·목차·검색을 사용해 봅니다.
- 새로고침 후 책과 읽던 위치가 유지되는지 확인합니다.
- 책장 백업을 다른 브라우저에서 복원해 봅니다.

앱 전체 소스와 배포 설정을 이 저장소에서 관리합니다.
