내 서재

로그인하지 않은 내 서재는 브라우저에만 저장됩니다. 로그인하면 해당 계정의 책 본문·챕터·제목·저자 모델·책장 구성·수동 책갈피를 Cloudflare D1에 저장하여 다른 기기에서도 API로 조회합니다. 책 목록은 본문과 분리하여 불러오고, 본문은 책을 열 때 해당 권만 가져옵니다. 로그인한 책의 본문은 브라우저 저장소에 보관하지 않습니다. 이미지 파일·표지 이미지·이미지 책갈피는 업로드하지 않고 기기에만 남습니다. 기존 비로그인 서재는 자동으로 업로드하지 않으며, 사용자가 가져오기를 선택할 때 계정 서재로 복사합니다.

Google 로그인

로그인 버튼을 누르면 Google 로그인 도구를 불러옵니다. 인증 서버는 Google이 발급한 토큰을 검증하며, 토큰에 포함될 수 있는 이메일·이름·사진은 저장하지 않습니다. Google 계정 식별자를 서비스 전용 식별자로 변환하여 로그인 상태 구분에 사용합니다. 이 식별자는 익명 정보가 아닌 가명 식별자입니다.

보관과 로그아웃

로그인 토큰은 브라우저 메모리에만 유지하며 새로고침·탭 닫기·로그아웃 또는 최대 1시간 뒤 만료 시 제거됩니다. 로그아웃 이전에 발급된 토큰은 만료 전까지 유효할 수 있습니다. 서버에는 계정 식별자와 연결된 텍스트 책이 사용자가 삭제할 때까지 보관됩니다. 책 삭제가 서버에서 완료되면 서버의 본문은 제거되며, 다른 기기에서 삭제된 책이 되살아나지 않도록 책 ID·계정 식별자·버전·삭제 시각은 남습니다. 제공자의 백업에는 복구 보관 기간 동안 이전 데이터가 남을 수 있습니다. 로그인 상태의 책 본문은 화면 메모리에만 유지되며 새로고침·탭 닫기·로그아웃 시 제거됩니다. 이미지와 이미지 표시 규칙은 계정별로 이 기기에만 보관되며 사이트 데이터를 지우면 제거됩니다.

외부 서비스

사이트는 GitHub Pages, 인증 서버는 Cloudflare Workers, 계정 인증은 Google을 이용합니다. 접속 IP 등 운영 정보는 각 제공자의 정책에 따라 처리될 수 있습니다. 인증 서버는 애플리케이션 요청 로그와 인증 토큰·본문 로그를 저장하도록 구성하지 않습니다.
